# Autumn Homepage Web

This is the frontend for the Autumn homepage

## Development

Prerequisites:
- [Bun](https://bun.sh/)
- [Rust](https://www.rust-lang.org/tools/install)
- [Dioxus-Cli](https://dioxuslabs.com/learn/0.6/getting_started/)

1. Install tailwindcss dependencies with `bun i`
2. Run tailwindcss cli to watch for CSS changes with `bunx @tailwindcss/cli -i ./input.css -o ./assets/tailwind.css --watch`
3. Run the application with `dx serve`
4. The application can be found at `http://localhost:8000`
